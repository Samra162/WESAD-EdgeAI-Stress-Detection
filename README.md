# WESAD-EdgeAI-Detection
# 🧠 IoT-Based Stress Detection using WESAD Dataset

## 📌 Project Overview
This project focuses on detecting human stress levels using physiological signals collected from wearable sensors. The system uses the **WESAD (Wearable Stress and Affect Detection)** dataset and applies data preprocessing and analysis techniques in Python (Google Colab).

The goal is to analyze sensor data and identify stress patterns in humans for healthcare and IoT-based monitoring systems.

---

## 📊 Dataset Information
The **WESAD dataset** includes multimodal physiological signals such as:
- ECG (Electrocardiogram)
- EDA (Electrodermal Activity)
- Respiration
- Accelerometer data

The dataset contains recordings from multiple subjects under different emotional states (stress, baseline, amusement).

---

## ⚙️ Project Workflow

1. **Data Loading**
   - Imported dataset files (S2 subjects)

2. **Data Preprocessing**
   - Handling missing values
   - Cleaning raw signals
   - Structuring data for analysis

3. **Exploratory Data Analysis (EDA)**
   - Visualization of physiological signals
   - Understanding stress vs non-stress patterns

4. **Feature Extraction**
   - Statistical features from sensor data

5. **Future Work Model Training**
   - Machine Learning models can be applied for classification of stress levels
